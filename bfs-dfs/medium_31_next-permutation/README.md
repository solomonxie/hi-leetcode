# 31. Next Permutation

LeetCode: https://leetcode.com/problems/next-permutation/

A permutation of an array of integers is an arrangement of its members into a sequence. The next permutation is the next lexicographically greater arrangement. If no such arrangement exists (the array is sorted in descending order), rearrange it as the lowest possible order (ascending). Must be done in place with O(1) extra memory.

## Example

```
Input: nums = [1,2,3]
Output: [1,3,2]

Input: nums = [3,2,1]
Output: [1,2,3]

Input: nums = [1,1,5]
Output: [1,5,1]
```
