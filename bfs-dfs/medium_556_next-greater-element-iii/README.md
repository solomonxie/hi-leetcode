# 556. Next Greater Element III

LeetCode: https://leetcode.com/problems/next-greater-element-iii/

Given a positive integer `n`, find the smallest integer which has exactly the same digits as `n` and is strictly greater than `n`. If no such positive integer exists, return -1. The answer must fit in a 32-bit integer.

## Example

```
Input: n = 12
Output: 21

Input: n = 21
Output: -1
```
