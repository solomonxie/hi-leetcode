# 226. Invert Binary Tree

LeetCode: https://leetcode.com/problems/invert-binary-tree/

Given the root of a binary tree, invert the tree (mirror it left-to-right at every node) and return its root.

## Example

```
Input: root = [4,2,7,1,3,6,9]
Output: [4,7,2,9,6,3,1]

Input: root = [2,1,3]
Output: [2,3,1]
```
