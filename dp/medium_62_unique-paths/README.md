# 62. Unique Paths

LeetCode: https://leetcode.com/problems/unique-paths/

A robot is located at the top-left corner of an `m x n` grid. The robot can only move either down or right at any point in time, trying to reach the bottom-right corner. How many possible unique paths are there?

## Example

```
Input: m = 3, n = 7
Output: 28

Input: m = 3, n = 2
Output: 3
Explanation: Right->Down->Down, Down->Right->Down, Down->Down->Right.
```
